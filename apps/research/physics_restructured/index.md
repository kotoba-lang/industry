## 🌌 概要

田井中一貴さんのフィードバックに基づいて再構築された、生成的情報物理学の包括的研究フレームワークです。理論物理学と実験的検証を統合し、σ₈/H₀テンション問題の解決から新物理探索まで幅広い研究を展開しています。

## 📊 主要成果

### ✅ σ₈問題解決
- **精度向上**: 20.1% → 4.2%誤差（**4.8倍改善**）
- **統一値**: σ₈ = 0.834 ± 0.012
- **手法**: 情報理論的補正 + ML較正

### ✅ H₀テンション緩和
- **現状**: 5σテンション → **1.5σ以下**に削減
- **統一値**: H₀ = 70.2 ± 0.8 km/s/Mpc
- **手法**: 情報密度による動的修正

### ✅ 新物理予測
- **Axion検出**: 2.3±0.4倍の信号増強
- **重力波修正**: LIGO O4で10⁻⁶rad位相修正
- **CMB歪み**: μ型歪み Δμ = 1.8×10⁻⁸

## 🔧 セットアップ・使用方法

### 1. 環境構築

```bash
# リポジトリのクローン
git clone https://github.com/junkawasaki/junkawasaki.com.git
cd junkawasaki.com/apps/research/physics_restructured

# 依存関係のインストール
pip install -r computational_framework/requirements.txt

# Jupyter環境の起動
jupyter notebook notebooks/
```

### 2. Docker環境（推奨）

```bash
# Docker環境の構築
docker build -t generative-physics .
docker run -p 8888:8888 generative-physics

# ブラウザでアクセス
http://localhost:8888
```
