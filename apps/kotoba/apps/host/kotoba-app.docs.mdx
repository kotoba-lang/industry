# Kotoba Platform

Kotoba Platformは、テキストエディターとグラフエディターを統合した包括的なプラットフォームです。

## 機能

- **テキストエディター**: ProseMirrorベースのリッチテキストエディター
- **グラフエディター**: Cytoscape.jsベースのインタラクティブグラフエディター
- **AST生成**: テキストからAST（抽象構文木）を自動生成
- **リアルタイム同期**: エディターとグラフ間のデータ同期
- **ダークモード対応**: ライト/ダークテーマの切り替え

## 使用方法

```tsx
import { KotobaApp } from '@junkawasaki/kotoba/kotoba-app';

function MyApp() {
  return <KotobaApp />;
}
```

## コンポーネント構成

- `@junkawasaki/kotoba/components/editor` - テキストエディターコンポーネント
- `@junkawasaki/kotoba/components/graph` - グラフ表示・編集コンポーネント
- `@junkawasaki/kotoba/components/host` - 統合ホストコンポーネント

## 技術スタック
