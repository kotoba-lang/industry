# `kotoba`言語 設計仕様書 (v0.2)

このドキュメントは、`kotoba`言語の技術的な設計仕様と、その根底にある哲学を定義します。

## 1. 思想: HoTTと空即是色

`kotoba`は、**ホモトピー型理論（HoTT）**の「型は空間である」という思想と、**般若心経**の「空即是色」の哲学を、プログラミング言語の構造に直接的に埋め込むことを試みます。

-   **`場` (ba):** HoTTにおける**型/空間 (Type/Space)**。すべての項（値）が存在するためのコンテキスト。
-   **`縁` (en):** HoTTにおける**パス/射 (Path/Morphism)**。`場`から`場`への関係性やプロセス。
-   **`間` (ma):** HoTTにおける**ユニット型/終対象 (Unit Type/Terminal Object)**。値が存在しない状態、すなわち「機会」や「静寂」を表す型。

この言語におけるプログラミングとは、**`空`から`場`を立ち上げ (`く`)、それに`式`の名と形を与え (`しき`)、`縁`で繋ぐ**という、構成的な証明プロセスそのものです。

## 2. 言語仕様: キーワード体系

| 役割 | **キーワード** | 読み | 形式意味論上の対応 |
| :--- | :--- | :--- | :--- |
| **型 (空間)** | `場` | ba | Space / Type |
| **型 (パス)** | `縁` | en | Path / Morphism |
| **型 (ユニット)** | `間` | ma | Unit Type / Terminal Object |
| **`create`** | `く` | ku | Declaration (`空`からの創出) |
| **`let`** | `しき` | shiki | Definition / Binding (`式`での定義) |
| **`fn`** | `かん` | kan | Lambda Abstraction (`観`による構成) |
| **`match`** | `おう` | ou | Induction / Case Analysis (`応`による分解) |

### 2.1. 構文例

```kotoba
// 「タイマー」という名の`場`を`空`より立ち上げ、
// 'timer_ba'という`式`でその形を定義する。
しき timer_ba: 場 = く "system/timer/1s"

// timer_baから、「間」に触れて「i64」を生み出す`縁`を取り出す。
しき ticks: 縁<間, i64> = timer_ba.as_en()

// 「数を二倍で観る」という`縁`を定義する。
しき doubler: 縁<i64, i64> = かん(x: i64) => x * 2

// 縁と縁を接続し、新しい`縁`を定義する。
しき pipeline: 縁<間, i64> = ticks |> doubler

// pipelineから生じる「果」を購読する。
// それを観る方法は以下の通り。
pipeline.subscribe(かん(val: i64) => {
    // 果（val）の様相に応（おう）じて、振る舞う。
    おう val {
        0 => system.print("始まりの刻"),
        _ => system.print(val)
    }
})
```

## 3. コンパイラ設計

`kotoba`コンパイラは、`kotoba`コードを最適化されたRustコードへ変換する**トランスパイラ**として実装されます。

### 3.1. コンパイルパイプライン

1.  **構文解析 (Parser)**: `kotoba-parser`が、上記のキーワード体系に基づくLL(1)再帰下降パーサとしてソースをASTに変換。
2.  **意味解析・型チェック**: `kotoba-compiler`がASTの型整合性を検証。
3.  **Rustコード生成**: `kotoba-compiler`がASTから等価なRustコード（`struct Ba`, `impl Stream`など）を生成。
4.  **最終コンパイル**: `rustc`がネイティブバイナリを生成。

### 3.2. プロジェクト構造 (Cargo Workspace)

-   `crates/`
    -   `kotoba-core`: `Ba` (`場`) など、言語のコアとなるデータ構造の定義。
    -   `kotoba-parser`: パーサーとASTの定義。
    -   `kotoba-compiler`: 意味解析、型チェック、コード生成器。
    -   `kotoba-cli`: CLIツール。
    -   `kotoba-std`: 標準ライブラリ。
