# `gen`言語 設計仕様書 (v0.1)

このドキュメントは、因果プロセス言語 `gen` の技術的な設計仕様と実装計画を定義します。

## 1. 思想と目標

`gen`は、**「因縁生起（Dependent Origination）」**の思想をプログラミングモデルとする言語です。システムの振る舞いを、静的な要素の集合としてではなく、**因（`in`）**と**縁（`en`）**の相互作用によって生じる動的なプロセスとして記述します。

-   **`in` (因)**: 全てのプロセスの**主因**。それ単体で存在し、アクションや状態の源となる単位。グラフにおける「頂点」。
-   **`en` (縁)**: `in`と`in`を繋ぐ**助縁**。因から生まれた結果を次の因へと伝える関係性、プロセス、あるいは経路そのもの。グラフにおける「有向エッジ」。

### 目標
-   複雑なシステムの動的な振る舞いを、因果関係として宣言的かつ直感的に記述できる構文を提供する。
-   Rustの所有権モデルをベースとした強力な静的解析により、実行時エラーの少ない堅牢なプログラムを記述できる。
-   Rustへのトランスパイルを通じて、高いパフォーマンスと既存のエコシステムへのアクセスを実現する。

## 2. 言語仕様

### 2.1. 字句構造

-   **キーワード**: `in`, `en`, `fn`, `let`, `create`, `match`

### 2.2. 型システム

`gen`は静的型付け言語です。

#### 2.2.1. プリミティブ型

-   `In`: プロセスの根源となる「因」。
-   `String`, `f64`, `i64`, `bool`: 基本的なデータ型。

#### 2.2.2. 複合型

-   **タプル**: `(T1, T2, ...)`
-   **構造体**: `struct Point { x: f64, y: f64 }`
-   **縁 (En)**: `en<Input, Output>`
    -   `gen`言語の中核をなす型。`Input`型の値を受け取り、`Output`型の値を非同期に生成するプロセス（縁）を表す。
    -   Rustの `async Stream` に相当する。

### 2.3. 構文

#### 2.3.1. 因（In）の生成

`create` キーワードを用いて `In` 型のインスタンスを生成します。

```gen
// create "<identifier>";
let timer_in: In = create "system/timer/1s";
```

#### 2.3.2. 縁（En）の定義と接続

`en` キーワードで縁を定義し、`|>` (パイプ) 演算子で因と縁、または縁同士を接続します。

```gen
// timer_inからi64を生成する「縁」を取り出す
let ticks: en<(), i64> = timer_in.as_en();

// 受け取ったi64を2倍にする新しい「縁」を定義
let doubler: en<i64, i64> = fn(x: i64) => x * 2;

// 縁と縁を接続し、新しい縁を生成
let pipeline: en<(), i64> = ticks |> doubler;

// 縁を購読し、結果（果）を処理
pipeline.subscribe(fn(val: i64) => {
    system.print(val); // 2, 4, 6, ... という「果」が生じる
});
```

## 3. コンパイラ設計

`gen`コンパイラは、`gen`コードを最適化されたRustコードへ変換する**トランスパイラ**として実装されます。

### 3.1. コンパイルパイプライン

1.  **構文解析 (Parser)**: `gen-parser`がLL(1)再帰下降パーサとしてソースをASTに変換。
2.  **意味解析・型チェック**: `gen-compiler`がASTの型整合性を検証。
3.  **Rustコード生成**: `gen-compiler`がASTから等価なRustコード（`struct In`, `impl Stream`など）を生成。
4.  **最終コンパイル**: `rustc`がネイティブバイナリを生成。

### 3.2. プロジェクト構造 (Cargo Workspace)

-   `crates/`
    -   `gen-core`: `In` など、言語のコアとなるデータ構造の定義。
    -   `gen-parser`: パーサーとASTの定義。
    -   `gen-compiler`: 意味解析、型チェック、コード生成器。
    -   `gen-cli`: CLIツール。
    -   `gen-std`: 標準ライブラリ。
