# hottgraph: 生成中心言語 `gen` の実装

[![Rust](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml/badge.svg)](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml)

`hottgraph`は、哲学・数理・物理・霊性を統合した「生成」を基本単位とする新しいプログラミング言語 `gen` の実装プロジェクトです。

## 概要

`gen`は、存在の根源を静的な「粒子」ではなく、動的な**「生成プロセス」**そのものであると捉える思想に基づいています。この言語は、情報、構造、さらには魂や生命といった複雑な概念が、どのようにして基本的な「生成」から生まれるのかを記述し、シミュレートすることを目的としています。

理論的な基盤として**ホモトピー型理論（HoTT）**の表現力にインスパイアされつつ、実装の安全性と速度は**Rust**の堅牢なシステムに依拠しています。

## プロジェクトの現在の状態

現在は、`gen`言語のコードをRustコードに変換する**トランスパイラ**の開発に着手したところです。

### 完了したステップ

1.  **プロジェクト初期セットアップ**: BitとCargoによるワークスペースを構築。
2.  **コア型定義**: `gen-core`クレートに`Gen`と`Soul`の基本Rust構造体を定義。

### 次のステップ

-   **パーサー実装**: `gen g := create "faith"` のような代入文を解釈できる最小パーサーを実装する。
