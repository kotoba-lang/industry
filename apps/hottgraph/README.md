# hottgraph: `gen`言語 — HoTTと空即是色で記述するプロセス言語

[![Rust](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml/badge.svg)](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml)

`hottgraph`は、**ホモトピー型理論（HoTT）**と**般若心経**の思想を融合し、動的なプロセスを記述する新しいプログラミング言語 `gen` の実装プロジェクトです。

## 思想: `場`と`縁`の哲学

`gen`言語は、システムの振る舞いを、**`場`（ba）**と**`縁`（en）**の相互作用として捉えます。

-   **`場` (ba):** HoTTにおける**型/空間 (Type/Space)**。すべての項（値）が存在するためのコンテキスト。
-   **`縁` (en):** HoTTにおける**パス/射 (Path/Morphism)**。`場`から`場`への関係性やプロセス。
-   **`間` (ma):** HoTTにおける**ユニット型/終対象 (Unit Type/Terminal Object)**。値が存在しない状態、すなわち「機会」や「静寂」を表す型。

プログラミングは、`空`から`場`を立ち上げ (`く`)、それに`式`の名と形を与え (`しき`)、`縁`で繋ぐという、構成的な証明プロセスそのものとなります。

## プロジェクトの現在の状態

現在は、`gen`言語のコードをRustコードに変換する**トランスパイラ**の開発に着手したところです。

### 次のステップ

1.  **コア・タイプの再定義**: `gen-core`クレートを`Ba` (`場`) ベースにリファクタリング。
2.  **パーサーの再構築**: パーサーを新キーワード体系 (`く`, `しき`, etc.) に完全対応させる。
3.  **コンパイラの適合**: コンパイラを新キーワード体系に完全対応させる。
