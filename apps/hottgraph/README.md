# hottgraph: プロセスグラフ言語 `gen` の実装

[![Rust](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml/badge.svg)](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml)

`hottgraph`は、**プロセスグラフ**の構築を通じて動的なシステムを記述する、新しいプログラミング言語 `gen` の実装プロジェクトです。

## 概要

`gen`言語は、システムの構成要素を**ノード（`Node`）**として定義し、それらの間を流れる値のストリームを**フロー（`Flow`）**として記述します。この`Node`と`Flow`の組み合わせによって、非同期処理や複雑なイベント駆動システムを、宣言的かつ視覚的に構築することを目的としています。

理論的な基盤として**ホモトピー型理論（HoTT）**や**グラフ理論**にインスパイアされつつ、実装の安全性と速度は**Rust**の堅牢なシステムに依拠しています。

## プロジェクトの現在の状態

現在は、`gen`言語のコードをRustコードに変換する**トランスパイラ**の開発に着手したところです。

### 完了したステップ

1.  **プロジェクト初期セットアップ**: BitとCargoによるワークスペースを構築。
2.  **コア型定義**: `gen-core`クレートに`Node`の基本となるRust構造体を定義。

### 次のステップ

-   **パーサー実装**: `let my_node: Node = create "..."` のような構文を解釈できるパーサーを実装する。
