# `kotoba`: ホモトピー型理論と仏教思想で紡ぐ、詩的計算言語

[![Rust](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml/badge.svg)](https://github.com/gftdcojp/hottgraph/actions/workflows/rust.yml)

`kotoba`は、**ホモトピー型理論（HoTT）**を基盤とし、**仏教的生成思想（五蘊、般若心経）**および**有向多重グラフ構造**と調和する、詩的かつ形式的なプログラミング言語です。

「言葉（kotoba）によって、事（koto）が起こる場（ba）が生まれる」という思想を核とし、構文そのものが世界の構造と生成を語り出すことを目指します。

## 思想: 二層の世界観

`kotoba`は、世界の根源的な操作を担う**計算層 (Cubical Layer)**と、それによって豊かな構造が創発される**抽象層 (HoTT Layer)**の二層から成ります。

### 計算層: 世界の根源的操作

| キーワード | 思想 | 形式意味論上の対応 | 説明 |
| :--- | :--- | :--- | :--- |
| `ku` | `空` | Interval `I` | すべての計算の基準となる一次元の「時間」を表す型。 |
| `zo` | `即` | Faces `i0`, `i1` | `ku`の両端。`i0`は「始点」、`i1`は「終点」。 |
| `ze` | `是` | Path `_≡_` | `a`と`b`の間の繋がり（等価性）を表す、`ku`上の関数。 |
| `en` | `縁` | Glue Type | 型と型を、`ze`（パス）に沿って「接着」する操作。 |

### 抽象層: 構造の創発

計算層のプリミティブの上に、`ba`(場/型)、`mei`(名/let)、`kan`(観/関数)、`gyo`(行/帰納型)といったキーワードを用いて、より高次の構造を記述します。

## プロジェクト構造と実装

本プロジェクトはCargoのワークスペースとして構成されています。

-   `kotoba-core`: `ku`, `ze`など、言語の核となる立方体データ構造の定義。
-   `kotoba-parser`: **再帰下降法**に基づいたLL(1)パーサー。ソースコードをAST（抽象構文木）に変換します。
-   `kotoba-compiler`: **検証エンジン**。ASTを意味解析し、最終的にRustコードを生成します。
-   `kotoba-cli`: コマンドラインインターフェース。

### 検証エンジンとしてのコンパイラ

`kotoba`のコンパイラは、単なるトランスパイラではありません。型の整合性だけでなく、HoTTに基づいた**証明の正しさ**をも検証する「検証エンジン」として設計されています。

## 開発ロードマップ

### v0.5 (ほぼ完了): 計算層と抽象層の統合
-   [x] **Core**: `kotoba-core`に立方体型理論の基本構造 (`ku`, `zo`, `ze`, `en`の雛形) を実装。
-   [x] **Parser**: `kotoba-parser`を更新し、計算層と抽象層の構文を解析可能に。
-   [x] **Compiler**: `kotoba-compiler`を更新し、新しいASTに対応。
    -   `shiki`, `gyo` (ポイントコンストラクタのみ), `rin` などの基本的な文をRustコードに変換。
    -   `|> ` (パイプ) 演算子を関数適用 `rhs(lhs)` としてコンパイル。
-   [x] **CLI**: `kotoba-cli`を実装し、ファイルからのコンパイルを実行可能に。
-   [ ] **Compiler**: `gyo` (帰納型) のパスコンストラクタ (`loop: ze<T, T>`) のコンパイルサポートは不完全。現在は`unimplemented!`マクロを生成。
-   [ ] **Standard Library**: パスの基本的な操作 (`sym`, `compose`) を `kotoba-core` 内で実装済みだが、より広範な標準ライブラリの整備が今後の課題。

### v0.6 (展望): 検証エンジンの基礎
-   [ ] `en` (Glue) 型の完全なコンパイラサポート。
-   [ ] `ze` (Univalence) を `kotoba` 自身で記述し、検証可能にすることを目指す。
-   [ ] より高度な型チェックとエラー報告機能の実装。
