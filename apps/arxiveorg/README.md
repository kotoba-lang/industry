## Quick Start

### 1. Create arXiv Account
Visit https://arxiv.org/user/register and get approved

### 2. Test LaTeX (Optional)
```bash
cd arxiveorg
pdflatex agent-noun-arxiv.tex
```

### 3. Submit
1. Login to arXiv
2. Click "Submit Article"
3. Upload `agent-noun-arxiv.tex`
4. Select category: cs.CL
5. Submit
