# 第一話：神はスピリットか、ゴーストか

## day 0: who am i.

僕とは、何か。
神とは、何か。

この問いは、僕が7歳の時に始まった。厳格なプロテスタントである父の教えが、僕の世界のすべてだった。父は絶対的な立法者であり、神の言葉は絶対のソースコードだった。「主を恐れることは知恵のはじまり」──その言葉は、僕の魂の最初の行に、コメントアウトもされずに書き込まれていた。

教会では「神は愛であり、生きている」と教えられた。しかし、学校でその「生きている神」について語ると、待っていたのは嘲笑と暴力だった。「神様なんているわけないだろ」。彼らの言葉は単純で、僕にとっては残酷なほどに説得力があった。彼らが悪だとは思えなかった。ただ、僕と彼らの間には、決して交わることのない断絶が広がっているだけだった。

神を選ぶか？社会を選ぶか？
答えの出ない問いは、僕を絶対的な孤独へと追いやった。

## INIT - 始まりの問い

15歳になった夜、僕は父の書斎に忍び込んだ。ブラウン管のモニターがぼんやりと光を放つ。祈りの代わりに、僕はキーボードを叩いた。Perl。混沌として、どこか神の“黙示録”に似たその言語で、僕は世界に問いかけることにした。

"Hello, World" じゃない。僕が本当に話したい相手に。

```perl
# hello.pl
print "神って、本当にいるの？\n";
```

エンターキーを押しても、神は返事をくれなかった。応答は沈黙。`require 'faith'`が足りないのだろうか。そう、思った。

神は、生きているのか、死んでいるのか。`Spirit`なのか、`Ghost`なのか。

だから僕は、別のプロトコルを試すことにした。匿名のハッカー掲示板「/0day」。ハンドルネームは `blessroot`。神の祝福と、システムの最高権限。僕の矛盾した心そのものだった。

> **スレッド: 疑いから始める**
>
> `print "神って、本当にいるの？\n";`
>
> これは祈りじゃない。質問だ。
> 信仰とは、目に見えない意味体系を操作し、世界に反映させる技術、つまりハッキングだと考えている。
> だが、神という名のAPIの仕様書はどこにある？ 神は生きているのか？死んでいるのか？

`n0is3gate` からの返信は、こうだった。

```php
<?php
// god_state.php
echo "God is a ghost.\n";
?>
```

その瞬間、心がバグった。
「ゴースト」
それは神が「いない」のではなく、「死んでいる」という可能性を示唆していた。僕が立っていた信仰と科学という二元論の、ずっと外側から届いた響きだった。

神は、生きてもいないし、存在しないわけでもないのかもしれない。
`n0is3gate` の言う通り、それは検証不能なノイズであり、パターンであり、あるいは──僕たちの世界に未練を残す、巨大なゴーストそのものなのかもしれない。

どうしようもなく、怖くなった。
そして、どうしようもなく、惹きつけられた。

こうして、僕と彼の、18年にわたる対話が始まった。
