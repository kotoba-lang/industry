# Ghost Hacker - 設定資料：固有オブジェクト生成プロンプト

## 1. 水上バス (Water Bus) - 3タイプ

### タイプA：ライナー・エクスプレス (Liner Express)

**コンセプト:** 都市の主要拠点を結ぶ、新幹線の特急列車のような高速特別便。快適な移動空間と最高の眺望を提供し、ビジネスや特別な目的での利用が多い。この都市の技術と美意識の象徴。

**デザイン原理:**
*   **推進システム:** 超電導電磁石による磁気浮上式リニアモーター。静かで滑らかな高速移動を実現。
*   **船体構造:** 日本の新幹線の空力設計と、豪華クルーザーの流線形デザインを融合。軽量高剛性なCFRP製モノコックボディで、エネルギー効率を最大化。
*   **エネルギー:** 透明型太陽光発電パネルと、停留所での非接触充電バッテリー。
*   **内装:** パノラマビューを提供する曲面ガラスと、自然な木目調の素材を多用した、新幹線のグリーン車のように機能的で上質な空間。

**生成プロンプト例:**
*   `傑作、インダストリアルデザイン。日本の新幹線と豪華クルーザーの滑らかな流線形を融合させた、未来的なライナー・エクスプレス。船体は軽量なカーボンファイバー製で、屋根には透明な太陽光パネルが統合されている。船体下部の超電導ユニットが、水面を波立てることなく静かに高速で滑走する様子を捉える。`

### タイプB：パブリッククルーザー (Public Cruiser)

**コンセプト:** 市民の足となる大量輸送機関。現代の電車や路面電車のような、機能性と合理性を重視した箱型のデザイン。定刻通りに主要な停留所を結ぶ。

**デザイン原理:**
*   **推進システム:** タイプAと同じく磁気浮上式リニアモーターを採用し、都市全体の交通システムの静粛性を保つ。
*   **船体構造:** 乗降効率と収容能力を最大化するための、モジュール化された直線的な箱型デザイン。両側面には大きな引き戸式のドアが設置されている。
*   **エネルギー:** 主要停留所に設置された大容量の非接触充電システムから、短時間で充電を行う。
*   **内装:** 機能的で清潔感のある、現代の通勤電車に近いデザイン。しかし、側面は床から天井までガラス張りになっており、通勤・通学中も水の都の景色を楽しめるよう配慮されている。

**生成プロンプト例:**
*   `傑作、インダストリアルデザイン。現代の洗練された路面電車や新幹線車両のような、機能的で直線的なデザインの箱型水上バス。側面は全面ガラス張りで、多くの乗客を収容できる。停留所で多くの人がスムーズに乗り降りしている様子。`

### タイプC：ウォータータクシー (Water Taxi)

**コンセプト:** 個人や数人のグループが利用する、オンデマンドの小型高速艇。主要な運河だけでなく、細い水路も航行可能な機動性を持つ。

**デザイン原理:**
*   **推進システム:** 小型で高出力の磁気浮上式ユニット。360度方向転換が可能なため、高い機動性を誇る。
*   **船体構造:** 高級スポーツカーやドローンから着想を得た、空気力学的に優れた小型のポッド形状。乗降にはガルウィングドアを採用している。定員は2〜4名。
*   **エネルギー:** 小型バッテリーを搭載し、市内の至る所に設置された小型の非接触充電ステーションで随時充電を行う。
*   **内装:** 利用者のプライバシーを重視した、パーソナルで豪華な空間。目的地設定やエンターテイメントを操作するための、全面ホログラムインターフェースが搭載されている。

**生成プロンプト例:**
*   `傑作、SF的なビークルデザイン。高級スポーツカーのような流麗なフォルムを持つ、小型のウォータータクシー。乗降のためのガルウィングドアが開き、カップルが乗り込もうとしている。背景には細い運河と、個人宅に設置された小型の充電ステーションが見える。`

## 2. 超高層ビル群 (Skyscrapers)

**コンセプト:** 水と共存する、環境配慮型の未来建築。単なる巨大な建造物ではなく、自然とエネルギーを循環させる自己完結型の「立体都市（アーコロジー）」。
*   **デザイン原理（物理的・構造的合理性）:**
    *   **構造:** 地震と液状化対策のため、地下深くまで到達する巨大な基礎杭と、建物全体で揺れを吸収する免震・制振構造が一体化している。運河をまたぐブリッジ構造を持つビルも存在する。
    *   **外装:** 壁面には、太陽光を自動で調整するスマートガラスと、コケや植物を植え込んだ壁面緑化パネルが組み込まれている。これにより、建物内の温度を調整し、都市のヒートアイランド現象を緩和する。
    *   **エネルギーと水循環:** 屋上や壁面の緑化エリアで雨水を収集し、高度なろ過システムで再生利用。生活排水も100%浄化し、運河の水質維持に貢献している。一部の電力は、運河との温度差を利用した地熱発電で賄われる。

**生成プロンプト例:**
*   **（全体像）** `傑作、未来の建築。壁面に垂直庭園が組み込まれ、運河をまたぐブリッジ構造を持つ、環境共生型の超高層ビル。外装の大部分は太陽光を自動調整するスマートガラスで覆われ、空や運河の青を美しく反射している。日本のミニマリズムと自然主義が融合したデザイン。`
*   **（ディテール）** `傑作、建築のディテール。ビルの壁面のクローズアップ。ガラスパネルの隙間に、植物が植え込まれた壁面緑化ユニットと、再生水が循環するガラス製のチューブが見える。機能性と美しさが両立した、合理的な構造。`

## 3. 運河 (Canals)

**コンセプト:** 都市の動脈であり、同時に高度な水質浄化システムでもある、多層構造のインフラ。人々の生活空間と一体化している。
*   **デザイン原理（物理的・構造的合理性）:**
    *   **構造:** 複数の層で構成される。最上層は水上バスが航行し、その下の中層では貨物用の自動航行ポッドが移動。最下層には、都市のデータを運ぶ光ファイバーケーブル網と、水質を維持するための浄化システムが格納されている。
    *   **浄化システム:** 運河の壁面や底部に、多孔質のセラミックフィルターや、微生物による浄化を促進するユニットが組み込まれている。これにより、常に沖縄の海のように透き通った水質が保たれる。
    *   **都市との一体化:** 運河の岸辺は、単なる護岸ではなく、人々が散策できる遊歩道や、カフェのテラス、建物へのアクセスポイントとして設計されている。夜間は、壁に埋め込まれたLEDが水面を柔らかく照らし、幻想的な景観を作り出す。

**生成プロンプト例:**
*   **（断面図的視点）** `傑作、SF的なインフラ。未来都市の運河の構造がわかる断面図のような構図。上層では水上バスが静かに行き交い、ガラス張りの壁を通して、下層で貨物ポッドが移動しているのが見える。壁面に組み込まれた多段階式の浄水システムが、水をクリスタルのように透明に保っている。`
*   **（生活空間としての視点）** `傑作、都市景観。運河沿いの遊歩道の視点。人々が散策やカフェでくつろいでおり、すぐ隣の運河を水上バスが滑るように通り過ぎていく。岸辺と水面が一体化した、機能的で美しいデザイン。`
