# Elias

- **名前:** Elias (エリアス)
- **職業:** 神学生
- **宗教:** プロテスタント (メソジスト派)
- **背景:**
  - 旧約聖書への深い理解を持つが故に、神を「畏れ」の対象として絶対視している。
  - その結果、神と人、そして人と人が根源的に分離した「individual」であるという独自の解釈を情報世界に見出している。
  - この解釈が、他者を愛したいと願いながらも愛せない、という深い精神的苦悩の原因となっている。
- **性格:**
  - 非常に思慮深く、真面目。
  - 内面に激しい葛藤を抱えている。
- **ゴーストとの関係:**
  - ゴーストを祓う対象とは考えていない。むしろ、自らの信仰や解釈を映し出す鏡として捉えている節がある。

# Elias - Portrait

- **髪:** 黒髪のショートヘア。整えられている。
- **目:** 鋭い眼差し。瞳の色はダークブラウン。
- **服装:**
  - 基本は白いシャツに黒いパンツ、シンプルなジャケットという清潔感のある服装。
  - 首からは常に小さな十字架のネックレスを下げている。
- **体格:** 細身で長身。
- **雰囲気:**
  - どこか近寄りがたい、ストイックな雰囲気を持つ。
  - しかし、話してみると真面目で誠実な人柄が伝わってくる。
- **イメージカラー:** ネイビー、ホワイト
- **モチーフ:**
  - 孤独に森の奥で思索するフクロウ。静かで、動かず、だが全てを見通しているような鋭さを持つ。
