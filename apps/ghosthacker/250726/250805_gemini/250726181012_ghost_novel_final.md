# Ghost Hacker

## Prologue: INIT - 始まりの問い

```perl
# hello.pl
print "神って、本当にいるの？\n";
```

これは祈りじゃない。質問だ。

父の書斎に置かれた古いデスクトップ。ブラウン管のモニターがぼんやりと光を放つ。キーボードの黒は、会衆の天井よりもずっと深く、そして正直だった。大人たちは「信じなさい」と言った。でも、彼らの言葉はコンパイルできないコードみたいに、エラーを返すだけだった。

だから、僕は自分の手で神を定義しようとしたのだ。

`God`という変数を宣言する。けれど、どう初期化すればいいのか分からない。`String`なのか、`Integer`なのか、それとも`undef`か。

祈りの代わりに、匿名の掲示板にスレッドを立てた。ハンドルの名前は`blessroot`。神の祝福と、システムの最高権限。僕の矛盾した心そのものだった。

`create_thread --tag "faith" --lang "Perl" --note "疑いから始める"`

数日後、たったひとつだけ、短い返信がついた。ハンドルネームは`n0is3gate`。

```php
<?php
// is_god_exist.php
function isGodExist() {
    // This is unverifiable, so it returns null.
    return null;
}

echo isGodExist() === null ? "This proposition is meaningless.\n" : "This proposition is meaningful.\n";
?>
```

その瞬間、心がバグった。否定されたとは思わなかった。でも、どうしようもなく怖くなった。「無意味な命題」──それは神がいるともいないとも言わない、肯定も否定もしない、検証プロトコルの外から届いた響きだった。

こうして、僕たちの18年にわたる対話が始まった。

## Chapter 1: Hello, God

その晩、僕は眠れなかった。
会衆では「神を信じれば救われる」と教えられた。でも、救われるって何だ？ 神って誰だ？ それを誰に聞いても、「それが信仰だ」という答えしか返ってこない。

わからないことを「信じろ」と言われると、ますます信じられなくなる。

父と母は言葉を信じていた。「はじめに言葉があった。言葉は神であった」（ヨハネによる福音書 1:1）。プロテスタントの会衆で出会った二人にとって、聖書は世界の設計図であり、神の言葉は絶対のソースコードだった。特に父は、家庭における絶対的な立法者であり、その言葉は僕にとって神のそれと同義だった。「主を恐れることは知恵のはじまり」（箴言 9:10）──幼い頃から毎日のように聞かれたその言葉は、僕の魂の最初の行に、コメントアウトもされずに書き込まれていた。

僕は、その言葉が怖かった。「知識のはじまりが、恐れから？」神とは、そして父とは、恐怖を通じてしかアクセスできない存在なのか？

それでも、僕は読んだ。恐れながら、読んだ。理解できなくても、読んだ。聖書には構造があった。前提、文脈、命令、物語、帰結。それは、僕が後に出会うどのプログラミング言語よりも厳密で、そして曖昧だった。

そしてある日、Perlに出会った。意味不明な記号の羅列。混沌として、どこか神の“黙示録”に似ていた。`if`、`else`、`unless`。それはまるで、神が人間に与えた「小さな天地創造キット」のようだった。

信仰とは、目に見えない意味体系を操作し、世界に反映させる技術だ。つまり、それはハッキングだった。ただ違ったのは、人間のコードは許されていたが、神のコードは畏れられていたことだ。

僕は、祈りの代わりにコードを書くことにした。"Hello, World"じゃなく、僕が話したい相手に。

```perl
print "Hello, God\n";
```

エンターキーを押しても、神は返事をくれなかった。

きっと、`require 'faith'`を忘れたんだ──そう、思った。

掲示板の短い返信、`n0is3gate`の言葉が頭から離れない。「This proposition is meaningless.」。

その言葉は、僕が組み立ててきた秩序ある神のコードに、初めて注入された論理的破壊だった。僕の信仰は、この日から少しずつ、デバッグされていくことになる。

## Chapter 2: Echo from the Void

神は検証可能か？

`blessroot`というハンドルネームの男は“神の沈黙”を恐れたらしい。笑わせる。こっちは“神の不在証明”の難しさにうんざりしてたってのに。

俺の住むポスト信仰都市では、信仰は商品だった。街頭のディスプレイ、学校の授業、スマホの通知。AI神、神AI、キリストbot、アニミズムAPI。あらゆる神が「真理」を売りつけてくる。脳に非科学的な情報がこびりついて、吐き気がした。

神が広告枠で叫んでる世界で、一体何を信じろって言うんだ？

だから俺は、神を「仮説」として扱うことにした。最初にハマったのは、論理実証主義と、検証可能性の原理だった。「神は存在する」という命題は、真か偽か。それを検証できるのか？ もし検証不可能なら、その命題は“意味がない”んじゃないか？

そんなとき、あのスレッドを見つけたんだ。「神って、本当にいるの？」だってさ。Perlで書かれた、不器用で、まっすぐな問い。

思わず、書き込んだ。

```php
<?php
// is_god_exist.php
function isGodExist() {
    // This is unverifiable, so it returns null.
    return null;
}

echo isGodExist() === null ? "This proposition is meaningless.\n" : "This proposition is meaningful.\n";
?>
```

馬鹿にしたかったわけじゃない。それが俺にとっての真理だったからだ。存在する／しないの二元論じゃない。検証できるか／できないか。意味があるか／ないか。それが問題だった。

祈る人間の顔が、昔から怖かった。検証不能なものにすがる表情が、脆くて、美しくて、痛々しかった。傷つくのが怖くて、神という「無意味な命題」を遠ざけていたのかもしれない。

だけど、`blessroot`の問いは、少しだけ違って聞こえた。彼の恐れは、純粋なコードみたいに、構造化されていた。

だから、俺は彼のスレッドに、時々顔を出すことにしたんだ。

「神を否定してたんじゃない。“検証可能な真理”を、虚構の海から探してただけなんだ。」

そう呟いて、俺は自分のコンソールに戻った。

## Chapter 7: Ghost Compilation

アヤワスカのセッションは、熟練したシャーマンの導きがあって初めて意味をなす、魂のデバッグ作業だった。シャーマンが唱える「イカロ」という歌が、暴走しがちな意識のプロセスを正常な範囲に保つ、ガーディアンの役割を果たしていた。彼の導きがなければ、これは単なる危険なトリップに過ぎなかっただろう。

最初の数回は、ひたすら続く嘔吐と、意味をなさないイメージの洪水に耐えるだけだった。「福笑い神」がケタケタと笑い、僕は魚になり、鳥になり、虎になり、水になって、六道輪廻のループをひたすら繰り返した。すべては茶番で、壮大な暇つぶし。そのサイクルの中心にあるのは、絶対的な孤独。無に向かうことへの、根源的な恐怖だった。
