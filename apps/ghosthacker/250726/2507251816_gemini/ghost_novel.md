# Ghost Hacker

## Prologue: INIT - 始まりの問い

```perl
# hello.pl
print "神って、本当にいるの？\n";
```

これは祈りじゃない。質問だ。

父の書斎に置かれた古いデスクトップ。ブラウン管のモニターがぼんやりと光を放つ。キーボードの黒は、教会の天井よりもずっと深く、そして正直だった。大人たちは「信じなさい」と言った。でも、彼らの言葉はコンパイルできないコードみたいに、エラーを返すだけだった。

だから、僕は自分の手で神を定義しようとしたのだ。

`God`という変数を宣言する。けれど、どう初期化すればいいのか分からない。`String`なのか、`Integer`なのか、それとも`undef`か。

祈りの代わりに、匿名の掲示板にスレッドを立てた。ハンドルの名前は`blessroot`。神の祝福と、システムの最高権限。僕の矛盾した心そのものだった。

`create_thread --tag "faith" --lang "Perl" --note "疑いから始める"`

数日後、たったひとつだけ、短い返信がついた。ハンドルネームは`n0is3gate`。

```php
<?php
echo "変数じゃなくて、ノイズかもよ。\n";
?>
```

その瞬間、心がバグった。否定されたとは思わなかった。でも、どうしようもなく怖くなった。「ノイズ」──それは神がいるともいないとも言わない、肯定も否定もしない、プロトコルの外から届いた響きだった。

こうして、僕たちの18年にわたる対話が始まった。

まだ誰も知らなかった。この“匿名の返信者”が、自分の中に住むもう一人の魂だということを。

## Chapter 1: Hello, God

その晩、僕は眠れなかった。
教会では「神を信じれば救われる」と教えられた。でも、救われるって何だ？ 神って誰だ？ それを誰に聞いても、「それが信仰だ」という答えしか返ってこない。

わからないことを「信じろ」と言われると、ますます信じられなくなる。

父と母は言葉を信じていた。プロテスタントの会衆で出会った二人にとって、聖書は世界の設計図であり、神の言葉は絶対のソースコードだった。「主を恐れることは知恵のはじまり」──幼い頃から毎日のように聞かされたその言葉は、僕の魂の最初の行に、コメントアウトもされずに書き込まれていた。

僕は、その言葉が怖かった。「知識のはじまりが、恐れから？」神とは、恐怖を通じてしかアクセスできない存在なのか？

それでも、僕は読んだ。恐れながら、読んだ。理解できなくても、読んだ。聖書には構造があった。前提、文脈、命令、物語、帰結。それは、僕が後に出会うどのプログラミング言語よりも厳密で、そして曖昧だった。

そしてある日、Perlに出会った。意味不明な記号の羅列。混沌として、どこか神の“黙示録”に似ていた。`if`、`else`、`unless`。それはまるで、神が人間に与えた「小さな天地創造キット」のようだった。

信仰とは、目に見えない意味体系を操作し、世界に反映させる技術だ。つまり、それはハッキングだった。ただ違ったのは、人間のコードは許されていたが、神のコードは畏れられていたことだ。

僕は、祈りの代わりにコードを書くことにした。"Hello, World"じゃなく、僕が話したい相手に。

```perl
print "Hello, God\n";
```

エンターキーを押しても、神は返事をくれなかった。

きっと、`require 'faith'`を忘れたんだ──そう、思った。

掲示板の短い返信、`n0is3gate`の言葉が頭から離れない。「ノイズかもよ」。

その言葉は、僕が組み立ててきた秩序ある神のコードに、初めて注入されたエントロピーだった。僕の信仰は、この日から少しずつ、デバッグされていくことになる。

## Chapter 2: Echo from the Void

神って、うるさいんだよ。

Akitoというハンドルネームの男は“神の沈黙”を恐れたらしい。笑わせる。こっちは“神の喋りすぎ”にうんざりしてたってのに。

俺の住むポスト信仰都市では、信仰は商品だった。街頭のディスプレイ、学校の授業、スマホの通知。AI神、神AI、キリストbot、アニミズムAPI。あらゆる神が「真理」を売りつけてくる。脳にノイズがこびりついて、吐き気がした。

神が広告枠で叫んでる世界で、一体何を信じろって言うんだ？

だから俺は、神を否定した。いや、正確には「フィルタ処理」することにしたんだ。最初にハマったのは、音声信号処理とノイズキャンセリングだった。「神の声が本物かどうか？」を見抜きたかった。もし“本物の神”がいるなら、あらゆるノイズを消した最後に、残るんじゃないか？

そんなとき、あのスレッドを見つけたんだ。「神って、本当にいるの？」だってさ。Perlで書かれた、不器用で、まっすぐな問い。

思わず、書き込んだ。

```php
<?php
echo "変数じゃなくて、ノイズかもよ。\n";
?>
```

馬鹿にしたかったわけじゃない。それが俺にとっての真理だったからだ。存在する／しないの二元論じゃない。世界はもっと混沌としていて、意味はノイズの中から生まれてくる。

祈る人間の顔が、昔から怖かった。何かにすがる表情が、脆くて、美しくて、痛々しかった。傷つくのが怖くて、神を遠ざけていたのかもしれない。

だけど、`blessroot`の問いは、少しだけ違って聞こえた。彼の恐れは、純粋なコードみたいに、構造化されていた。

だから、俺は彼のスレッドに、時々顔を出すことにしたんだ。

「神を否定してたんじゃない。“本当の神”を、ノイズの海から探してただけなんだ。」

そう呟いて、俺は自分のコンソールに戻った。

## Chapter 3: Dual Boot

16歳の夜、ふと、自分の記憶が自分のものじゃない気がした。
思い出そうとすると、そこに重なった声があった。それは、母でもなく、父でもなく──どこか懐かしい“他人の自分”の声だった。

掲示板のスレッドに書き込んだ。ハンドルネームは、もちろん`blessroot`。

> **件名: 記憶の所有権について**
>
> ```javascript
> // memory.js
> let memory = ["church_scenery", "mother's_cry", "someone's_anger"];
> memory.owner = "?";
> ```
>
> 自分の中に、知らない構造がある気がする。他人の記憶が、自分のものとして再生される。これって、バグだろうか？

すぐにレスがついた。`n0is3gate`からだった。

> ```javascript
> // soul.js
> let memory = ["your", "mine", "ours"].shuffle();
> let soul = memory + emotion + intention;
> ```
>
> 「魂は構造だ」

その言葉に、頭を殴られたような衝撃を受けた。魂？ 宗教や哲学の言葉だと思っていた。だが、彼の手にかかると、それはまるでJSONオブジェクトのように、冷たく、そして美しく構成されていた。

魂って何だ？ 感情？ 意志？ 記憶？ それとも、複数人で同時に読み書きできる、共有メモリのようなプロトコル？

宗教ではなく、理屈として、もう一度考えたくなった。魂があるとして、それはコードにできるのか？

その夜、僕は自分という構造体を再定義するように、コードを書き続けた。

```json
{
  "soul": {
    "memory": ["教会の風景", "母の泣き声", "誰かの怒り"],
    "emotion": ["不安", "罪悪感", "好奇心"],
    "intention": ["つながりたい", "理解したい", "自由になりたい"]
  }
}
```

書きながら気づいた。この記憶のいくつかは、自分の経験じゃない。「母の泣き声」は知っている。でも「誰かの怒り」は？ これは誰の感情だ？

僕の魂は、すでに複数の存在がアクセスできる、マルチスレッドな情報構造体になっているのかもしれない。

掲示板にもう一つ、問いを投げかけた。

> 「魂にアクセスするには、どんなインターフェースが必要だと思う？」

`n0is3gate`は、すぐには答えなかった。
数日後、彼が無言で投げてきた一行のコードが、僕の次の問いへの扉を開けた。

```python
def soul():
    yield from open('feeling://self')
```

情緒がインターフェースだった。
感じることで、魂はアクセス可能になる。論理じゃない、共鳴だったんだ。

### Chapter 6: Backdoor: 母というブラックボックス

母は、ブラックボックスだった。入力と出力は観察できる。だが、その内部でどんなプロセスが動いているのか、僕には到底理解できなかった。彼女の言動は、しばしば非論理的で、感情の欠落したアルゴリズムのように見えた。

レンの存在を知ってから、僕は確信した。僕の魂にバックドアを仕掛け、レンという魂をインストールしたのは、母以外にありえない。彼女は、自らの「罪」──レンを守れなかったという深い悲しみを、僕というコンテナにデプロイすることで処理しようとしたのではないか。もちろん、無意識に。

> **Posted by: blessroot**
>
> ```bash

> install --source "mother" --target "akito" --payload "ren.soul" --method "guilt"

>

この問いに、`n0is3gate`は答えなかった。僕自身も、答えを探していた。

真実を知るには、通常のプロトコルでは足りない。デバッガをアタッチし、メモリの奥深くにアクセスする必要があった。僕は、南米のジャングルで使われるという幻覚植物、アヤワスカの存在を知った。それは、意識のファイアウォールを一時的に無効化し、魂のルート権限にアクセスする、究極のハッキングツールだと噂されていた。

危険な賭けだ。しかし、僕はこのブラックボックスを開けなければならなかった。母が何を思い、何を僕に託したのか。そして、僕の中にいるレンとは、何者なのか。

僕は、最初のセッションの予約を入れた。真実を求めて、自分自身の魂に、クラッキングを仕掛けるために。
- **C (Philosophy)**: 家族、特に親が「ブラックボックス」として子の魂に影響を与える構造を問う。無意識の行為が、意図せぬバックドアを生む霊的セキュリティの問題を提起する。
