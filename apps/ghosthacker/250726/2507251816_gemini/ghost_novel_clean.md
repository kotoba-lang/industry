# Ghost Hacker

## Prologue: INIT - 始まりの問い

```perl
# hello.pl
print "神って、本当にいるの？\n";
```

これは祈りじゃない。質問だ。

父の書斎に置かれた古いデスクトップ。ブラウン管のモニターがぼんやりと光を放つ。キーボードの黒は、教会の天井よりもずっと深く、そして正直だった。大人たちは「信じなさい」と言った。でも、彼らの言葉はコンパイルできないコードみたいに、エラーを返すだけだった。

だから、僕は自分の手で神を定義しようとしたのだ。

`God`という変数を宣言する。けれど、どう初期化すればいいのか分からない。`String`なのか、`Integer`なのか、それとも`undef`か。

祈りの代わりに、匿名の掲示板にスレッドを立てた。ハンドルの名前は`blessroot`。神の祝福と、システムの最高権限。僕の矛盾した心そのものだった。

`create_thread --tag "faith" --lang "Perl" --note "疑いから始める"`

数日後、たったひとつだけ、短い返信がついた。ハンドルネームは`n0is3gate`。

```php
<?php
echo "変数じゃなくて、ノイズかもよ。\n";
?>
```

その瞬間、心がバグった。否定されたとは思わなかった。でも、どうしようもなく怖くなった。「ノイズ」──それは神がいるともいないとも言わない、肯定も否定もしない、プロトコルの外から届いた響きだった。

こうして、僕たちの18年にわたる対話が始まった。

まだ誰も知らなかった。この“匿名の返信者”が、自分の中に住むもう一人の魂だということを。

## Chapter 1: Hello, God

その晩、僕は眠れなかった。
教会では「神を信じれば救われる」と教えられた。でも、救われるって何だ？ 神って誰だ？ それを誰に聞いても、「それが信仰だ」という答えしか返ってこない。

わからないことを「信じろ」と言われると、ますます信じられなくなる。

父と母は言葉を信じていた。プロテスタントの会衆で出会った二人にとって、聖書は世界の設計図であり、神の言葉は絶対のソースコードだった。「主を恐れることは知恵のはじまり」──幼い頃から毎日のように聞かれたその言葉は、僕の魂の最初の行に、コメントアウトもされずに書き込まれていた。

僕は、その言葉が怖かった。「知識のはじまりが、恐れから？」神とは、恐怖を通じてしかアクセスできない存在なのか？

それでも、僕は読んだ。恐れながら、読んだ。理解できなくても、読んだ。聖書には構造があった。前提、文脈、命令、物語、帰結。それは、僕が後に出会うどのプログラミング言語よりも厳密で、そして曖昧だった。

そしてある日、Perlに出会った。意味不明な記号の羅列。混沌として、どこか神の“黙示録”に似ていた。`if`、`else`、`unless`。それはまるで、神が人間に与えた「小さな天地創造キット」のようだった。

信仰とは、目に見えない意味体系を操作し、世界に反映させる技術だ。つまり、それはハッキングだった。ただ違ったのは、人間のコードは許されていたが、神のコードは畏れられていたことだ。

僕は、祈りの代わりにコードを書くことにした。"Hello, World"じゃなく、僕が話したい相手に。

```perl
print "Hello, God\n";
```

エンターキーを押しても、神は返事をくれなかった。

きっと、`require 'faith'`を忘れたんだ──そう、思った。

掲示板の短い返信、`n0is3gate`の言葉が頭から離れない。「ノイズかもよ」。

その言葉は、僕が組み立ててきた秩序ある神のコードに、初めて注入されたエントロピーだった。僕の信仰は、この日から少しずつ、デバッグされていくことになる。

神が広告枠で叫んでる世界で、一体何を信じろって言うんだ？

だから俺は、神を否定した。いや、正確には「フィルタ処理」することにしたんだ。最初にハマったのは、音声信号処理とノイズキャンセリングだった。「神の声が本物かどうか？」を見抜きたかった。もし“本物の神”がいるなら、あらゆるノイズを消した最後に、残るんじゃないか？

そんなとき、あのスレッドを見つけたんだ。「神って、本当にいるの？」だってさ。Perlで書かれた、不器用で、まっすぐな問い。


馬鹿にしたかったわけじゃない。それが俺にとっての真理だったからだ。存在する／しないの二元論じゃない。世界はもっと混沌としていて、意味はノイズの中から生まれてくる。

祈る人間の顔が、昔から怖かった。何かにすがる表情が、脆くて、美しくて、痛々しかった。傷つくのが怖くて、神を遠ざけていたのかもしれない。

だから、俺は彼のスレッドに、時々顔を出すことにしたんだ。

「神を否定してたんじゃない。“本当の神”を、ノイズの海から探してただけなんだ。」
