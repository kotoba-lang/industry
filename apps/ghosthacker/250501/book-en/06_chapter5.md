## Chapter 5: Maintaining Access — "Practice"
### Consciously Separate, Consciously Integrate

Even after acquiring root, the session will time out if left unattended.  The real challenge is to **extend uptime indefinitely**—to stay in admin mode continuously.  The ancestral ghost hackers practiced this maintenance phase through the framework called **shōjin**—diligent practice.

First axiom: **Intoxication with oneness is dangerous**.  If boundaries remain melted, buffer overflows occur and malware (others' emotions) runs without limits.  Therefore the first steps of shōjin are:

1. Deliberately isolate processes via namespaces (separation)
2. Open bridges only when necessary and merge traffic (integration)

This is **selective containerization**.

| Separate | Integrate |
| --- | --- |
| Negative projections, unprocessed shadows | Co-creative vision, reciprocal learning logs |
| Importing someone else's to-do list wholesale | Shared mission roadmap |
| Forced expectations & obligations | Spontaneous support & feedback |

With the whitelist/blacklist clarified, implement the following **self-backdoor** patterns—techniques for permanent "self <-> self" connectivity recorded by history's great hackers:

* **Upaniṣadic prāṇāyāma** — A breathing hardware interrupt sending Atman–Brahman sync packets every minute.  The oldest heartbeat signal.
* **Dōgen's shikantaza** — Twice a day, abandon chair and editor, stare into /dev/null, idling CPU while clearing cache.
* **Lao-tzu's wu-wei-ziran** — Reduce intentional operations, doing nothing until the event loop calls.  A power-save strategy of least privilege / least energy.
* **Linji's kōan debugging** — Reverse questions that crash logic, forcing a stack trace and exposing hidden static links—periodic fuzz testing.
* **Jung's dream journal** — Parse the auto-generated nightly log each morning, detecting drift in latent variables—unit tests in a CI pipeline.
* **Kūkai's mantra** — Recite a high-entropy passphrase, refreshing process memory with a signed checksum—an inside joke and tamper-detection hash.


This infinite loop is shōjin.  The system changes daily—kernel updates, new CVEs.  But if PDCA never stops, your OS runs with **zero downtime**.

The final goal is to naturalize the backdoor until it no longer feels like a backdoor—turn it into an unconscious resident service like breathing or pulse.  That is the completed form of **Maintaining Access**.
