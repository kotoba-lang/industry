# AST Processing Feature

テキストからAST（抽象構文木）を生成し、グラフデータに変換する機能です。

## 機能

- **テキスト解析**: マークダウンやプレーンテキストを解析
- **AST生成**: 構造化されたASTデータを生成
- **グラフ変換**: ASTデータをグラフ表示用に変換
- **データ検証**: ASTデータの整合性を検証
- **インポート/エクスポート**: JSON形式でのデータ交換

## 使用方法

```typescript
import { ASTProcessor } from '@junkawasaki/kotoba/features/ast-processing';

// テキストからASTを生成
const text = `
# タイトル
## サブタイトル
- リスト項目1
- リスト項目2
  - ネストした項目
`;

const astData = ASTProcessor.processText(text);

// データを検証
const isValid = ASTProcessor.validateASTData(astData);

// JSONとしてエクスポート
const json = ASTProcessor.exportToJSON(astData);
```

## サポートするテキスト形式

- **マークダウンヘッダー**: `#`, `##`, `###` など
- **リスト**: `-`, `*`, `+` で始まる行
- **番号付きリスト**: `1.`, `2.` など
- **コードブロック**: ``` で囲まれた部分
- **引用**: `>` で始まる行
- **段落**: 通常のテキスト行

## ASTデータ構造

```typescript
interface ASTNode {
  id: string;        // ノードの一意識別子
  label: string;     // 表示用ラベル
  type: string;      // ノードタイプ
  group: string;     // グループ分類
  level: number;     // 階層レベル
}

interface ASTEdge {
  source: string;    // 開始ノードID
  target: string;    // 終了ノードID
  weight: number;    // エッジの重み
}
```
