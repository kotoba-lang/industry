TROUBLESHOOTING QUICK REFERENCE
================================================================================

Issue: Staging nodes failing to boot
  → Check JVM startup logs
  → Verify Chicory can load WASM
  → Check memory and disk space

Issue: Parity divergence detected
  → Automatic rollback fires at 1% × 1min
  → Review divergence in parity-validation.log
  → Investigate root cause (cljc bug vs test artifact)
  → If app-level fix: fix in staging, re-validate, resume

Issue: Latency spike >150ms
  → Check GC pause times (jvm_gc_pause_ms)
  → If GC-related: expected during baseline, will improve Month 2
  → If sustained (>5min): investigate Chicory/WASM overhead

Issue: Memory growing unbounded
  → Automatic rollback fires at 512MB sustained
  → Check heap trend: tail metrics/parity-validation.log | jq '.jvm_heap'
  → Memory leak suspected: generate heap dump and analyze

Comprehensive troubleshooting: See deploy/MONTH-1-OPERATIONS-GUIDE.md
