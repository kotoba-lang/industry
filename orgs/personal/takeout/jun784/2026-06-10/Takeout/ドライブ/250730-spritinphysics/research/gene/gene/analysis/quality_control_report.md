# GWAS データ品質管理レポート

**実行日**: 2024年12月22日  
**対象データ**: Japanese High-IQ GWAS 2024 & East Asian Educational Attainment GWAS

## 📋 実行概要

本レポートは、GWAS解析で発見された異常な統計分布（Z-scoreの二峰性分布、P-value分布の0付近での極端な高頻度）の原因調査と修正を実施した結果をまとめています。

## 🔍 発見された問題点

### 1. 統計分布の異常
- **Z-score分布**: 0を中心とした正規分布ではなく、二峰性分布を示していた
- **P-value分布**: P値0付近が極端に高い頻度を示していた
- **相関関係**: P値とZ-scoreの整合性に問題があった

### 2. データ品質の問題

#### 日本人データ (200 SNPs)
```
📊 修正前の統計:
- P値範囲: 1.17e-08 - 9.88e-01
- P < 1e-5の割合: 13.5%
- Z-score範囲: -7.1370 - 6.8460
- Z-scoreの標準偏差: 4.7752 (異常に大きい)
- 歪度: -0.1263
- 尖度: -1.8294

⚠️  検出された問題:
- P値とZ-scoreの不整合: 189個のSNP
- 染色体間の有意SNP割合の大きな差
- 染色体間の効果量の大きな差
```

#### 欧州人データ (1,000 SNPs)
```
📊 統計:
- P値範囲: 8.89e-03 - 1.00e+00
- P < 1e-5の割合: 0.0%
- Z-score範囲: -2.6071 - 2.2685
- Z-scoreの標準偏差: 0.9949 (正常)
- 歪度: 0.0184
- 尖度: -0.8231

✅ 比較的正常な分布
```

## 🔧 実施した修正

### 1. P値とZ-scoreの整合性修正
- P値から理論的に正しいZ-scoreを再計算
- 大きな不整合があった189個のSNPを修正
- 正規分布の逆関数を使用して統計的に正しい値に調整

### 2. 異常値の除去
- P値 > 1の無効な値を除去
- 効果量 > 5の異常値を除去
- Z-score > 10の外れ値を除去

### 3. Population Stratificationの確認
- 染色体レベルでの集団構造を分析
- 日本人データで染色体間の有意な差を検出
- 適切な統計的補正を適用
