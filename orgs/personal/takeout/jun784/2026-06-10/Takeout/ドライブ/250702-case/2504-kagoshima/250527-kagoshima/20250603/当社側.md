1. 公的研究費不正使用に関する内部規則要件と貴学の対応の瑕疵

1.1 通報受理要件（公的研究費の不正使用に係る調査等に関する取扱規則 第3条第2項）の充足性

貴学「公的研究費の不正使用に係る調査等に関する取扱規則」（平成26年10月16日規則第42号。以下「取扱規則」という。）第3条第2項は、通報受理の要件として、通報内容に「不正使用の事案の内容等が明示され、かつ、不正使用とする合理的な根拠が示されたもの」であることを求めております。

当方が令和6年5月2日付で行った通報は、以下の具体的事実と証拠を明確に提示しており、上記要件を完全に満たしております。

	•	被通報者：鹿児島大学 瀬戸山准教授
	•	関連事業者：株式会社ファインシステムズ
	•	不正疑義の内容：下記２．記載のとおり。

２．不正疑義の具体的内容
瀬戸山准教授が主導した一般競争入札手続において、以下の重大な不正行為の存在が強く疑われます。
	1.	特定業者への露骨な優遇条件設定の強行
	•	本件入札は、随意契約ではなく一般競争入札であるにもかかわらず、仕様書及び入札要項において「株式会社ファインシステムズのシステム仕様に準拠すること」等、株式会社ファインシステムズ以外の事業者を実質的に排除する条件を意図的に設定したものであり、これは偽計入札妨害に該当する可能性があります。
	2.	特定業者利用を強要する不当な圧力
	•	入札後に行われた公式な会議の席上において、瀬戸山准教授及び古谷教授が「ファインシステムズ社への委託をなぜ行わないのか」等と発言し、公正な選定プロセスに対し明確な圧力を加えた事実は、強要未遂または職権濫用に該当する可能性があります。
	3.	契約履行に対する組織的なサボタージュ及び妨害行為
	•	契約締結後、株式会社ファインシステムズからの情報提供の遅延を口実として、当社の開発環境へのアクセスを不当に遅延させ、更には契約履行に向けた協議・折衝を一方的に中断するなど、契約の円滑な履行を意図的に妨害する行為が断続的に確認されております。これは、契約上の信義則に著しく違反するものです。
	4.	入札参加機会を著しく毀損する悪質な情報隠蔽
	•	入札募集要項及びその添付資料に関して、競争参加者の判断に不可欠な情報（動物実験システムのマニュアル、アクセス情報等）の提供を不当に遅延させました。
	•	その結果、株式会社ファインシステムズ以外の競争参加者は、十分な準備期間を確保することが不可能となり、契約履行において著しく不利な状況に追い込まれました。これは、公正な競争を著しく阻害する行為です。

上記の通り、当方の通報は「不正使用とする合理的な根拠」を具体的に示しており、取扱規則第3条第2項第1号の要件を明白に満たしております。したがって、貴学が「合理的な根拠が示されていない」として本通報の受理を拒否したことは、取扱規則の趣旨を著しく逸脱する不当な措置であると言わざるを得ません。

また、貴学監査室より令和6年6月3日付電子メールにて「5月2日付け別途レタックスにてお送りいただいた内容を具体的な根拠とお考えである旨確認しました」との連絡がございましたが、そもそも当方が令和6年5月29日付にて貴学学長宛に送付した書面は、監査室長殿個人に宛てたものではありません。加えて、通報内容のどの部分が「具体的な根拠」として不足しているのか、あるいはどの点が不明瞭であるのかについて、貴学からは一切具体的な指摘がなされておりません。さらに、予備調査における「証拠の真偽確認」に関する取扱規則の適用の可否についても、何ら回答を得られておりません。かかる貴学の対応は、予備調査及び本格的な監査の実施を意図的に回避しようとするものと強く推認され、貴学の監査体制が著しく機能不全に陥っており、かつ恣意的な運用がなされていることの証左と見なさざるを得ません。本件に関する貴学の不作為は、監査責任者たる監査室長 楠原 良成 様の責任問題として、文部科学省への告発事項に含める所存です。

1.2 予備調査手続（取扱規則第4条）の懈怠

仮に、貴監査室内において「証拠の真偽確認が困難」等の技術的な課題が存在するのであれば、取扱規則第4条の規定に基づき、速やかに「予備調査」を実施すべき義務があります。

取扱規則第4条は、通報を受理した場合、監査室長は直ちに統括管理責任者（担当理事）へ報告し、統括管理責任者は学長へ報告の上、事実関係確認のための予備調査を指示できると定めています。そして、予備調査は通知後14日以内に結果を報告し、学長は通報受付後30日以内に本調査の要否を判断しなければならないと規定されております。

貴学は「合理的な根拠が示されていない」との見解を示しておりますが、上記取扱規則の規定に照らせば、少なくとも予備調査を実施し、その結果に基づき本調査の要否を学長判断として協議する義務があります。したがって、監査室長の判断のみをもって本通報を門前払いすることは、取扱規則に違反する明白な職務懈怠です。

2. 文部科学省ガイドラインおよび監督権限の指摘

2.1 ガイドラインの通報受理・予備調査義務（研究費管理・監査ガイドライン Ⅱ－A－1－3）

文部科学省「研究機関における公的研究費の管理・監査のガイドライン（実施基準）」では、通報窓口は匿名・記名を問わず合理的根拠があれば受理し、予備調査を開始することが求められています。具体的には、不正疑義通知後30日以内に予備調査を行うことが推奨されています。

2.2 透明性ある調査体制（Ⅱ－B－2－1）

同ガイドラインでは、調査委員会には学内外の有識者（弁護士・公認会計士等）を含む公正な体制を構築することが義務付けられています。

2.3 通報者・被通報者保護の重視（Ⅱ－C－1）

通報者の保護と被通報者の名誉保護の両立を図りつつ、誹謗中傷目的の通報を排除しても、実質的な調査を怠らないことが最重要とされています。

2.4 監督権限

文部科学省は各国立大学法人の運営状況を監督する立場にあり、大学が内部規定やガイドラインに反して調査を行わない場合、是正措置を指示します。また、研究費配分元（文科省・JSPS・各省庁）にも報告されることが求められるため、貴学の対応が不十分であれば大学運営に対する外部監督が強化され、最悪の場合には研究費返還命令や助成停止などの制裁的措置が講じられるおそれがあります。

3. 一般競争入札における不正疑義と法令・内部規則違反

3.1 公示義務違反（契約事務取扱規則 第8条）

鹿児島大学「契約事務取扱規則」第8条では、一般競争入札の際に入札日の少なくとも10日前までに所定掲示板で公告し、公告には「競争入札に付する事項」「参加資格」「契約条項の閲覧場所」「入札日時・場所」「入札保証金」「遵守すべき規則」等を明示することが義務付けられています。本件では、入札公告前に「特定の業者を利用すべき」と示唆する動きがあり、公告による情報公開を前提とした公正な競争機会を奪う行為に該当すると判断いたします。

3.2 競争妨害行為の禁止（第3条第3項）

同規則第3条では、以下の行為を行った者を競争参加資格停止の対象と定めています。
	1.	公正な競争の執行を妨げ又は不正の利益を得るために連合した者（談合）
	2.	落札者が契約を結ぶこと又は契約者が履行することを妨げた者（入札妨害）
	3.	技術的若しくは経済的に競争に不利となるように条件を変更した者　など

本件の不正疑義は以下のとおりです。
	•	随意ではない一般競争入札において特定の業者を指定した疑義
	•	入札公告前に「株式会社ファインシステムズへの連携を強く示唆した」録音データがあり、一般入札で特定業者を排除する意図があった。
	•	特定業者を利用するように恣意的な発言を行った疑義
	•	入札関係者に対し、特定業者を利用するよう圧力をかける発言が複数回記録されており、公正な意思決定を著しく損ねる行為と判断される。
	•	特定業者による情報提供遅延を理由として意図的に他社の入札準備を妨害した疑義
	•	仕様書および見積依頼資料の提供をあえて特定業者にだけ先行させ、他社の準備を遅らせることで競争機会を不当に制限した。

これらはいずれも、「公正な競争の執行を妨げ」又は「競争参加者を技術的・経済的に不利とさせる」行為に該当し、契約事務取扱規則第3条第3項各号に違反するものです。

3.3 取引停止措置要件（取引停止等要項 第6条）

鹿児島大学「物品購入等契約に係る取引停止等要項」第6条では、談合や入札妨害行為が判明した場合、当該業者を一定期間取引停止（資格停止）とすることが定められています。具体的には、談合や競売入札妨害が認定された場合には2か月以上12か月以内の取引停止処分を科す旨が規定されています。
本件の特定業者優遇・情報隠蔽行為が事実と認定されれば、大学として厳正に資格停止の処分を講じる必要があります。

3.4 自治法上の契約原則（地方自治法 第234条・第234条の2）

地方自治法第234条では、「契約は原則として一般競争入札を行うものとし、指名競争入札・随意契約は例外的にしか認めない」ことが定められています。また第234条の2では、「契約担当職員は契約履行を確保するための監督・検査を行わなければならない」と規定されています。

国立大学法人もこれに準じ、入札の透明性・公平性を担保する義務があります。したがって、特定業者の優遇や情報提供遅延は、地方自治法の趣旨に反するとともに、内部規則違反であり、法的に重大な問題を含むものです。

4. 要請事項

以上を踏まえ、以下の対応を**至急（概ね7営業日以内）**にご実施くださいますよう要請いたします。

	1.	公的研究費不正使用に関する予備調査の実施と結果報告
	•	鹿児島大学「公的研究費の不正使用に係る調査等に関する取扱規則」第4条に基づき、本通報を正式に受理し、学長指示の下、14日以内に予備調査を開始してください。
	•	予備調査期間終了後、調査結果報告書を当方へ提出願います。
	
	2.	一般競争入札手続における違反疑義の予備調査と是正措置
	•	鹿児島大学「契約事務取扱規則」第3条第3項および第8条に該当する可能性のある特定業者優遇・情報隠蔽等の事実関係を確認し、事実と認定される場合は該当教職員の関与を明らかにした上で、当該業者を取引停止（資格停止）とし、契約を取消してください。
	•	監査室長から統括管理責任者（担当理事）および学長へ通報し、予備調査を指示していただきたく存じます。

	3.	調査委員会の設置（公正な体制整備）
	•	文部科学省ガイドラインⅡ－B－2－1に則り、学内外の弁護士・公認会計士等を含む公正・透明性の高い調査委員会を設置し、本調査へ移行してください。
	•	調査委員会の構成・役割分担およびスケジュール案を併せてご提示願います。

	4.	学長・統括管理責任者への速やかな報告
	•	監査室長から統括管理責任者および学長へ書面での正式報告を行い、本調査実施について最終判断を仰いでください。
	•	本調査へ移行する場合は、学長決裁印押印済みの決定書の写しを開示いただきたく存じます。

	5.	監事・会計検査院への情報提供検討

学内監査だけで不十分と判断した場合は、学内監事および会計検査院に事情を報告し、外部監査を実施いただくよう要請いたします。

本件は、一部のプロジェクト及びプロジェクト責任を持つ特定の個人らによる倫理観と信義則に反した不適切な行為に起因する問題であり、これにより貴学全体の評価が不当に損なわれる事態は、当方としても断じて望むものではありません。むしろ、本件を貴学の自浄作用及び国立大学法人としてのコンプライアンス体制の健全性を内外に示す好機と捉え、断固たる姿勢で予備調査を速やかに実施されることを、改めて強く要請いたします。
