# カオナビ訴訟対応資料




本リポジトリには、株式会社カオナビ（原告）とGftd Japan株式会社（被告）間の訴訟に関する資料が整理されています。

## フォルダ構成

### 当社側の主張
- 当社（被告）側の主張や証拠となるメール、書類などを格納
- 主なファイルとして「緊急：当社担当者の突然の退職に伴う契約に関する重要なお知らせ」や支払い関連の通知が含まれる

### 相手側の主張
- 原告側の主張や証拠となる書類
- PDFファイルや画像ファイルが含まれる
- `transcriptions` フォルダには各証拠書類の文字起こしが含まれる

### 答弁書履歴
- 答弁書の作成履歴が含まれる
- 各バージョンは日時を含むファイル名で管理

### 答弁書雛形
- 裁判所提出用の答弁書のテンプレート（雛形）

### 裁判所に提出する書類一式
- 最終的に裁判所に提出する書類一式を格納
- `pdf` フォルダには答弁書と証拠資料が含まれる

## 訴訟の概要

- 訴訟内容：カオナビサービス料金請求に関する紛争
- 争点：
  1. 解約申し出の有効性（2023年10月10日付）
  2. サービスサポート費用の妥当性
  3. 既払金の一部返還請求

## 使用方法

1. 最新の答弁書は `裁判所に提出する書類一式/pdf/答弁書.pdf` を参照
2. 証拠資料は各証拠番号（甲第X号証）に対応するファイルを参照
3. 追加の証拠資料を準備する場合は、`裁判所に提出する書類一式/pdf/README.md` を参考に適切なファイル名を付与
