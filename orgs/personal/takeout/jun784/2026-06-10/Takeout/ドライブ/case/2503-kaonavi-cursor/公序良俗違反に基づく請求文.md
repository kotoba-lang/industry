# 公序良俗違反に基づく請求文

## 1. 契約条項の片務性と公序良俗違反

### 1.1 片務的契約条項の問題点

本件利用規約は、以下の通り極めて片務的な条項により構成されており、民法第90条に定める公序良俗に反する無効な契約である。

#### **A. カオナビ側の一方的有利性**

1. **第7条第3項** - 年14.5%の高率遅延利息
   - 顧客の支払遅延に対し、法定利率（年3%）の約5倍の高率な遅延利息を課す
   - 現在の経済情勢下では著しく過大な利率

2. **第6条第5項** - 一方的な料金請求権の保持
   > 「事由のいかんを問わず、解約された場合であっても、当社はお客様へのサービス料金の請求権を失わないものとし、又は、既に受領した料金の返還義務を負わないものとします」
   - 契約解除の理由を問わず、一切の返金を拒否
   - 顧客の解約権を事実上無効化

3. **第15条** - 責任制限条項
   - 「当該賠償の累計総額は、当社に故意又は重過失がある場合を除き、当該損害の発生日から起算して過去12ヶ月間にお客様が当社に支払った本サービス料金の総額を限度とします」
   - 自社の責任を大幅に制限し、実質的な賠償を回避

4. **第14条第3項** - 過大な違約金
   - 規約違反時に「月額のサービス料金の合計金額の36か月分を違約金」
   - 実損害を大幅に超える懲罰的な違約金

5. **第26条** - 一方的な規約変更権
   - 顧客の同意なく規約の変更・追加・廃止が可能
   - 契約の基本的対等性を破壊

#### **B. 顧客側の一方的不利益**

1. **厳格な支払義務**
   - 年14.5%の遅延利息による重い負担
   - サービス不履行時でも支払義務継続

2. **解約の困難性**
   - 一切の返金なし
   - 解約料として残期間分の全額支払い

3. **過大な違約金負担**
   - 36か月分という実損害を大幅に超える金額
   - 実質的な契約拘束として機能

4. **一方的な規約変更の受忍**
   - 不利益変更を拒否する権利の剥奪
   - 継続的な契約関係の不安定化

### 1.2 公序良俗違反の法的構成

#### **A. 客観的要素（社会の一般的道徳観念に反する）**

1. **契約の双務性・対等性の破壊**
   - 一方当事者のみが著しく有利な条件を享受
   - 他方当事者は一方的に不利益を強制される構造

2. **経済的弱者への過度な負担**
   - 高率遅延利息による経済的圧迫
   - 解約の事実上の不可能性

3. **信義則・公平の原則に反する**
   - 給付と反対給付の著しい不均衡
   - 一方当事者の利益のみを優先した契約設計

#### **B. 主観的要素（反社会的意図）**

1. **暴利行為の意図**
   - 高率遅延利息による不当な利益取得
   - 過大な違約金による顧客の囲い込み

2. **対等な契約関係の排除**
   - 顧客の合理的な契約解除権の封じ込め
   - 一方的な契約条件の押し付け

## 2. 請求の趣旨

### 2.1 主位的請求（契約の一部無効）

**第1項** 被告の利用規約第6条第5項、第7条第3項、第14条第3項、第15条、第22条第2項、第26条の各規定は、民法第90条により無効であることを確認する。

### 2.2 第1次予備的請求（不当利得返還請求）

**第2項** 被告は、原告に対し、無効な契約条項に基づき取得した不当利得金○○○万円及びこれに対する不当利得時から支払済みまで年3%の割合による遅延損害金を支払え。

### 2.3 第2次予備的請求（損害賠償請求）

**第3項** 被告は、原告に対し、公序良俗に反する契約条項により原告に生じた損害金○○○万円及びこれに対する不法行為時から支払済みまで年3%の割合による遅延損害金を支払え。

### 2.4 第3次予備的請求（反訴としての遅延損害金請求）

**第4項** 原告は、被告の本訴請求に対し、以下の反訴を提起する。

1. **債務不履行による遅延損害金**
   - 被告の適切なサービス提供義務違反
   - 担当者突然の退職による業務継続の阻害
   - 解約申出の不当な拒絶

2. **不当利得返還請求に対する遅延損害金**
   - 無効な契約条項に基づく過剰な料金徴収
   - 返還義務の不履行による遅延損害金（年3%）

## 3. 請求の理由

### 3.1 民法第90条（公序良俗違反）の適用

本件利用規約の上記各条項は、以下の理由により公序良俗に反し無効である：

1. **一方当事者の著しい不利益** - 顧客に対する過度な負担の集中
2. **契約の対等性の破壊** - 双務契約の本質的要素の欠如
3. **経済的弱者への搾取** - 暴利行為に該当する不当な利益取得
4. **信義則違反** - 継続的契約関係における信頼関係の破壊

### 3.2 不当利得返還請求権（民法第703条）

無効な契約条項に基づき被告が取得した利益は法律上の原因を欠く不当利得であり、原告は民法第703条に基づきその返還を求める権利を有する。

### 3.3 損害賠償請求権（民法第709条）

被告が公序良俗に反する契約条項を故意に作成・運用し、原告に損害を与えた行為は不法行為に該当し、原告は民法第709条に基づき損害賠償を請求する権利を有する。

### 3.4 反訴としての遅延損害金請求

被告の本訴請求に対し、原告は以下の遅延損害金を反訴として請求する：

1. **民法第415条に基づく債務不履行の遅延損害金**
2. **民法第419条に基づく法定利率（年3%）による遅延損害金**
3. **対等な契約条件に基づく相互の遅延損害金請求権**

## 4. 結論

本件利用規約の片務的条項は、現代の契約法理念に反する不当な内容であり、民法第90条により無効である。

原告は、公序良俗に適合した対等な契約関係の確立と、被告の不当な利益の返還を求めるものである。
