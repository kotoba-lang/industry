
# Data security and AI rules

The outgoing Package A v1.1 ZIP is intentionally unencrypted and password-free
under explicit project-owner authorization for this one internal transfer to
Jun Kawasaki. After receipt, restrict access to Kawasaki's controlled local
research environment. Do not publicly redistribute, forward, or mirror the
package.

The package contains pseudonymous individual case PGS and an internal provider
workbook. Never upload individual PGS rows, workbook rows, sample tables, or
other restricted data to an external AI tool, public paste service, public
repository, or external/public cloud service. AI assistance may use only
schemas, field definitions, dummy data, and aggregate error summaries. Do not
record credentials, tokens, secret keys, or passwords in code, logs,
filenames, reports, or command history.

Package B is excluded and remains custodian-only until the independent return
archive is hash-locked. The return archive should follow the encrypted-return
specification unless the project owner separately changes it.
