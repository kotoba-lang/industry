## L5 階層マップ現在地 (1 段落ずつ)

- **L1 storage (Filecoin PoRep/PoSt)**: 安定。変化の中心は storage 自体ではなく
  報酬構造 — FIP-0118 (Q4 予定) が報酬を paid usage に紐付ける方向、FIL+ 廃止 +
  Service Rewards Actor 議論 (#1249/#1262, draft) が進行。storage proof 自体の
  設計変更は今週観測されず。
- **L2 availability (PDP)**: hot storage / PDP は mainnet で稼働継続。規模は小
  (71.34 TiB / 34 providers)、7 日で 284 missed proving periods — proving の
  堅牢性にまだムラがある。 https://pdp.filecoin.cloud/graphql-api
- **L3 transmission (NKN PoR)**: 変化なし。VRF ベース sigchain の V2 が stable
  であることが改めて文書化された (2026-06 頃の解説記事)。帯域「中継量」の証明は
  確立済みだが、配送の有用性 (受信側品質) は対象外のまま。
- **L4 delivery (AIOZ PoD)**: 変化なし。Vision Paper V2 の proof 分離構造 (PoS /
  PoD / PoT) は維持。AIOZ Stream の VOD ローンチ記事あり (日付 unknown) —
  proof 仕様レベルの更新は観測されず。
- **L5 performance / useful delivery (未解決)**: 未解決のまま。ただし隣接領域で
  動きあり: (1) Bittensor SN105 Beam が「bytes × latency × route correctness」の
  検証付き配送を報酬対象に運用開始済み (信頼モデルの詳細 unknown)、(2) Filecoin が
  報酬を paid usage / retrieval メトリクスに繋げる議論を開始 (draft 段階)。
  trustless な latency 証明 (受信者時計・Sybil・地理性) を正式に解く仕様は
  今週観測した範囲ではまだ出てこない。dVPN/DePIN 系の 2 次情報 (squirrelvpn blog 等)
  に PoB の challenge-response / ZK receipt 記述があるが質が低く、一次仕様は未確認。
