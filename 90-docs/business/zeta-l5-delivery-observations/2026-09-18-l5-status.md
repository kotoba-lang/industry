## 5 階層マップの現在地 (1 段落ずつ)

**L1 storage (Filecoin PoRep/PoSt)** — proof 層は現状維持。経済層で動き: FIP-0118 Solstice が 2026-09 accepted (upgrade スケジュール待ち)、Oct 15 vesting 終了。報酬が paid settlement の検証ゲートに接続されつつある。unknown: acceptance の正確な日付、upgrade 実施時期。

**L2 availability (PDP)** — 変化なし。PDP は mainnet 稼働中、FOC の core concept として文書化済み (https://docs.filecoin.cloud/core-concepts/pdp-overview/)。PoRep 系 retrieval checker (Spark) の終了により、retrievability 証明は PDP へ収斂した状態が継続。

**L3 transmission (NKN PoR)** — 変化なし。PoR はランダム抽出パケットの signature chain で relay を検証する設計のまま (https://pkg.go.dev/github.com/nknorg/nkn/v2)。帯域・レイテンシの性能証明は対象外のまま。直近 1 週間の仕様変更: 観測できず (unknown)。

**L4 delivery (AIOZ PoD)** — 変化なし。Vision Paper V2 の PoS/PoD/PoT 3 proof 分離が現行設計基準点。PoD は viewer 署名 receipt (nonce + timestamp + sequence) の Merkle バッチを Task Ledger に anchor する設計 (https://aioz.network/aioz-vision-v2.pdf)。実装進捗の新規観測なし (unknown)。

**L5 performance / useful delivery (未解決)** — 未解決のまま。新規提案・論文は観測されず (unknown)。隣接シグナル: DoubleZero Edge の商用レイテンシ配信拡大、Filecoin の paid settlement ゲート構造 (検証ゲート型報酬の構造的類似)。
