## L5 階層マップ現在地 (各層1段落)

**L1 storage (Filecoin PoRep/PoSt)** — 冷保存の暗号経済的証明は成熟域。ネットワーク容量 1.95 EiB 超 (filecoin.io)。ただし L1 自体の課題は PoRep/PoSt の封印コストとともに、経済面: Fil+ 10x multiplier が RBP を 87% 減らした実績があり、Solstice (FIP-0118) が検証なし 10x 乗 + paid-usage 連動報酬へ再設計しようとしている (accepted、mainnet 実装は未観測 → unknown)。出典: https://filecointldr.io/ https://filecoin.io/

**L2 availability (PDP)** — PDP は hot storage の保有証明として mainnet 運用中。FOC mainnet では 49.41 TiB / 478 datasets / 81 payer wallets (報道値、2026-09 前半)、SP は storage success ≥95%、PDP fault <1%、retrieval success ≥95% の基準で除去される。PDP explorer で proof status / fault 履歴が公開。Proof Record が PDP 成功を payment trigger にする構造は、証明→決済の直結という点で L5 への先行例。出典: https://docs.filecoin.cloud/core-concepts/architecture/ https://www.bitget.com/news/detail/12560605377904

**L3 transmission (NKN PoR)** — PoR (relay 量 × online 時間係数の報酬) に仕様変更なし。25,000 nodes 規模・17M+ tx の mainnet は安定的に relay 量を報酬対象化しているが、PoR が証明するのは「リレーした量」であり、帯域の真値や遅延の検証はスコープ外のまま。2026-06 の技術解説 (Medium) で signature chain + VRF + MOCA の設計が再説明された程度。出典: https://medium.com/nknetwork/under-the-hood-of-nkn-9083934e1a3b https://docs.nkn.org/

**L4 delivery (AIOZ PoD)** — Vision Paper V2 の 3 proof 分離 (PoS/PoD/PoT) に変更なし。PoD は viewer 署名入りレシート (segment ID + seq + timestamp + nonce) を Edge が redeem し、レシートの Merkle root を Task Ledger にアンカー。anti-replay と監査可能性の設計は明確だが、レシートが「配信された」ことしか証明せず、帯域・レイテンシ・品質の測定は Reputation Score (uptime/監査結果/SLA 違反履歴) に依存する。DePIN 数 328,012 / delivery 26,409 TB (aioz.network 表示値)。出典: https://aioz.network/aioz-whitepaper-v2.0.pdf

**L5 performance/useful delivery (未解決)** — 今週の最大の観測は、L5 に最も近い実装が Filecoin 側に現れたこと。FilBeam は egress をデータセット単位で計量し、delivery proofs をオンチェーン監査可能にして pay-by-egress で決済する — 「配送されたバイト量」を支払い対象にする primitive。ただしこれは配信量の計量であり、usefulness (受信者にとっての実効帯域・レイテンシ・品質) の証明にはまだ届かない: レイテンシは "cache hit で ms / miss で seconds" の設計目標表現で、trustless な受信者時計・RTT 検証は見えない。NEAR Proof of Response (応答性の経済拘束) と FilBeam (配送量の計量決済) が L5 を下から挟むが、両者の間の「有用配送そのものの証明」は依然 open。出典: https://docs.filecoin.cloud/core-concepts/retrieval/ https://docs.filecoin.cloud/introduction/about/
