# ADR-2607093400: ai-gftd-yukkuri パチンコ企画 — 月商1000万円到達のためのハイブリッド収益モデル

- **Status**: proposed（分析・提案のみ。実行着手はオーナー未決定）
- **Related**: `orgs/gftdcojp/ai-gftd-yukkuri` の `content/channels.edn` / `content/growth.edn` / `content/pachinko.edn` / `docs/pachinko-youtube-runbook.md.edn`、ADR-2605302130（kotoba write-scaling gate）、ADR-2607031540（yukkuri render path → cloud-murakumo）

## Context

`ai-gftd-yukkuri` の「ゆっくりパチンコ・パチスロch」（`UCby4cwshBD3WBGIzHS_woSA`）は
名機の歴史・確率の数値解説・ホール文化の3シリーズで構成され、`channels.edn` に
「実機実践・煽り・必勝法・設定看破で稼ぐ系は扱わない」というコンプライアンス invariant
が明文化されている。企画・トピックカタログ（576件）・生成パイプラインは in-repo で
完成しているが、実行は次の4ブロッカーで止まっている（2026-07-09 時点棚卸し）:

1. YouTube OAuth refresh-token 未投入（既存チャンネル、ユーザー操作待ち）
2. ComfyUI（画像生成）— 物理Macホストがオフラインで 502
3. k8s クラスタ（`vke-31d5f7dc-…`）到達不能（2026-07-03 判明、CronJob 経路は defunct）。
   新経路 `cloud-murakumo` CLI への移行は未着手（ADR-2607031540 follow-up）
4. kotoba write-scaling gate（ADR-2605302130）未解消 — produce が共有 kotoba pod を
   反復 degrade させるため live cron を回せない

`growth.edn` 自身の1年後想定（confidence:low）は 登録者 15,000 / RPM ¥200/1,000回で、
月商換算で概ね ¥4〜10万円。一方 YouTube 上のパチンコ系メディアで再生数・収益規模が
大きいのは「実戦（じっせん）」＝ホールからの稼働・来店協力金モデルであり、これは
`channels.edn` の compliance invariant と正面から対立する（実戦系ホール協賛は本チャンネルの
スコープ外）。

オーナーから「月商1000万円達成に適したビジネスモデルキャンバスを分析せよ」との依頼を受け、
現行方針（コンプライアンス重視）を維持したまま到達可能なモデルを検討した。

## Decision

**実戦・ホール協賛モデルへの転換は推奨しない**（`channels.edn` の invariant と正面衝突するため）。
代わりに、現行チャンネルの信頼ブランドを起点にした **3脚のハイブリッドモデル** を提案する。
目標到達状態（目安 M24 = 実行開始から24ヶ月後）での分担:

| 収益脚 | 目標月商 | 位置づけ |
|---|---|---|
| **B2B審査対応済みPR制作**（メーカー/ホール向け新台紹介・施設紹介動画） | ¥650万（10社 × 平均¥65万の月次リテナー） | 最大収益源。既存 compose→script→voice/visual→render→review パイプラインを受託制作に転用 |
| **スペックDB/アプリライセンス**（576件DBのアプリ化＋B2Bデータライセンス） | ¥260万（B2C ¥140万 + B2Bライセンス ¥120万） | ストック収益。既存DBが土台なのでゼロからではない |
| **メンバーシップ**（YouTube membership + コミュニティ） | ¥40万（想定500人 × ¥800） | 単体では小さいが、B2B営業の「熱心なファンがいる」説得材料として機能 |
| 広告（規模拡大分） | ¥50万 | 残差 |
| **合計** | **¥1,000万/月** | |

**フライホイール**: チャンネルの「射幸誘導ゼロ・出典明記」ブランド → B2B営業の説得材料
（炎上しない実績） → B2B収益でDB/アプリ開発に投資 → DBの権威性がチャンネルの
value proposition を強化 → 登録者/メンバー増加 → 次のB2B商談の裏付け、という循環。
この循環は B2B脚が立ち上がらないと回らない。

**着手優先度**: B2B営業・法務体制の立ち上げ ＞ DB商品化 ＞ メンバーシップ機能。
理由: B2B脚だけが既存チームに無い機能（営業担当・コンプラ法務レビュー体制・
クライアント向け進行管理）を新規構築する必要があり、他2脚は既存資産（576件DB /
既存チャンネル視聴者）の延長で立ち上がるため。

## Consequences

- **前提としてまず Context の4ブロッカー解消が先行する。** `growth.edn` の登録者/RPM想定は
  confidence:low の仮値であり、本ADRのハイブリッドモデルの実測検証にはまず週次投稿を
  実際に public で回して CTR/AVD/実RPMのベースラインを取る必要がある。
- B2B脚は現行 `ai-gftd-yukkuri` の設計・チームに無い機能（営業担当・コンプラ法務レビュー・
  クライアント進行管理）を要する。これは content/pipeline 中心の現行スコープの拡張であり、
  `CLAUDE.md` の Migration Backlog には未登録 — 着手する場合は別途タスク化が必要。
  本ADRは分析・方針の提示に留め、上記の具体タスク化・実装はスコープ外。
- 実戦・ホール協賛モデルは収益ポテンシャルが本ADR案より大きい可能性があるが、
  `channels.edn` の compliance invariant と対立するため**本チャンネルでは扱わない**。
  仮に踏み込む場合は、風営法・景表法の再評価と YouTube gambling content policy の
  リスク精査を前提に、現行チャンネルとは別ブランド・別法人格として切り出すこと
  （本ADRのスコープ外、着手する場合は別ADRで扱う）。
- 数値はすべて公開情報・repo内既存想定からの概算であり、監査済み財務データではない。
