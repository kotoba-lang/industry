## 検証 (21:48 更新 — 自律運転を実証)
- pnl / ops: builtin (scheduler) 実行で completed を確認 (21:27:44-47)。次回 21:57 自動。
- growth: succeeded 実行済み (sellers ledger 更新 18:14)。次回 22:16。
- mktg: provider 修復後 agent run は glm ループが長時間化する観測。次回 00:12。
- 障害と原因: 17:45-20:49 に 3 回の gateway restart が走り、in-flight builtin 実行が
  claimed のまま孤児化した (restart race — 既知の fleet 問題)。孤児 claim は
  executions.db で status='unknown' に手動更新して解消。クリーンな gateway では
  claim→完了するが、94-99 profile の multiplex で claim→start に最大 ~13 分の
  キュー遅延がある (正常動作、30m 周期には十分間に合う)。
- 教訓: cron 実行が claimed で止まって見えたら、まず gateway restart 履歴を疑い、
  executions.db の孤児 claim を掃除して次 tick を待つ。
