# Kotoba API

Kotoba PlatformのバックエンドAPIサービスです。

## 機能

- **AST処理**: テキストからAST（抽象構文木）を生成
- **グラフデータ管理**: グラフエディター用のデータ管理
- **RESTful API**: 標準的なREST APIエンドポイント
- **WebSocket**: リアルタイム通信対応

## 技術スタック

- NestJS
- TypeScript
- Node.js
- Express

## API エンドポイント

### AST関連
- `POST /api/ast/generate` - テキストからASTを生成
- `GET /api/ast/:id` - ASTデータを取得
- `PUT /api/ast/:id` - ASTデータを更新

### グラフ関連
- `POST /api/graph/save` - グラフデータを保存
- `GET /api/graph/:id` - グラフデータを取得
- `DELETE /api/graph/:id` - グラフデータを削除

## 開発

```bash
# 開発サーバー起動
npm run start:dev

# ビルド
npm run build

# テスト実行
npm run test
```
